Bảo mật local

Vault mã hóa bằng master password. Trang này chỉ chạy trong extension — website bên ngoài không truy cập được. Khóa vault khi rời máy.

Thêm tài khoản

Nhập từ Kaspersky / CSV

Hỗ trợ file TXT (Kaspersky → Xuất ra file text), CSV hoặc JSON. File backup kpm_vault.edb vẫn mã hóa — không import trực tiếp.

Xuất TXT từ Kaspersky (đúng file bạn vừa tạo)

  1. Kaspersky Password Manager → Cài đặt → Nhập / Xuất.
  2. Xuất ra file text — định dạng Website name / URL / Login / Password, khối cách nhau bởi ---.
  3. File TXT không mã hóa — giữ kín, xóa sau khi nhập xong nếu cần.
